# VukaFit Membership Quotation

A C++ console application that calculates student gym membership quotations based on membership fees, membership duration, and applicable discounts.

## 📌 About the Project

VukaFit Membership Quotation is a beginner-friendly C++ project designed to calculate gym membership costs for students.

The application demonstrates how programming can be used to solve a practical problem by accepting user input, performing calculations, and displaying a membership quotation.

## ✨ Features

- Calculates gym membership fees.
- Applies duration-based discounts where applicable.
- Calculates membership quotations based on user input.
- Displays the calculated quotation in the console.
